# Exercício 09: Tipos de Dados em C

Na linguagem C, os tipos de dados básicos são fundamentais para definir que tipo de informação uma variável pode armazenar:

1. **int**: Usado para armazenar números inteiros (sem casas decimais).
   - **Exemplo**: `int idade = 25;`
2. **float**: Usado para armazenar números de ponto flutuante (com casas decimais) de precisão simples.
   - **Exemplo**: `float preco = 19.99;`
3. **char**: Usado para armazenar um único caractere (letra, número ou símbolo).
   - **Exemplo**: `char sexo = 'M';`
